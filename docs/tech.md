Backend:
    Django + Django REST Framework

Database:
    PostgreSQL + PostGIS

Frontend:
    (web) React + TypeScript + Tailwind + MapLibre
    (mobile) Java Android App

Map sources:
    Basemap: OpenFreeMap
    Routing: Geofabrik Alberta OSM extract (https://download.geofabrik.de/north-america/canada/alberta.html). This needs updating every once a while.

DevOps:
    Docker + GitHub Actions
    AWS + Kubernetes (stretch)
