# Scope

## Minimum Viable Product
A navigation app.

The user can:
- view an interactive map (of Alberta)
- search or select an origin and destination
- display a route
- view distance and estimated duration

## Important later features

- search nearby places
- live turn-by-turn navigation
- global map
- real-time rerouting
- own algorithms for routing

## Probably not happening until much later

- Android app
- traffic-aware routing
- AWS deployment
- Kubernetes
